💬 Commentaries:

Completes the IAM permissions-domain alignment (IAM v1.3.0): re-enables permission enforcement
using the new tag-based permissioning standard, adapted to this module's generic per-entity
routing.

---

🔧 Changed:

    ▸ Replaced the dynamic entity/CRUD permission codes (`AUX_<ENTITY>` R/C/U/D) with dynamic
      permission tags built per request: `auxdata.<entity>.read` and `auxdata.<entity>.manage`.
      Read endpoints accept either tag; write endpoints require `.manage`.

    ▸ Switched the auth guard from `requireAll()` to `iam/permission->requireAny()`, matching the
      standard across the module suite.

---

ℹ️ Notes:

    ▸ Because aux entities are resolved dynamically from the route, this module ships no static
      permission seed — the `auxdata.<entity>.*` tags are expected to be registered alongside each
      aux entity's own definition.
